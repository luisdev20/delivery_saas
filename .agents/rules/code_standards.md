# Reglas de Código del Proyecto

1. **Sin emoticonos ni emojis**: No utilizar emojis ni emoticonos en el código fuente, interfaz de usuario (UI), mensajes, logs, ni comentarios.
2. **Comentarios mínimos y concisos**: Mantener comentarios breves, directos y únicamente cuando sean estrictamente necesarios. Evitar explicaciones extensas o redundantes.
